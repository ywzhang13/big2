# 麻將牌桌配音素材（老柯 2026-11-26）

- 用途：打牌唸牌名、吃碰槓胡自摸唸動作（程式：`lib/mahjong/tableVoice.ts`、`lib/mahjong/fx/engine.ts` 的 `playVoice`）。
- 來源：老闆提供的 `麻將聲音牌面.mp3`（29.9 秒，35 段）、`麻將音效動作.mp3`（4.4 秒）、`二萬.mp3`（1.6 秒）。
- **這個資料夾是一年長快取（README「靜態素材快取」）：換聲音一律改版號（`.v2.mp3`），不可同檔名換內容**；改完跑 `node scripts/asset-hashes.mjs --write`。
- 切法：用 ffmpeg `silencedetect`（-40dB、0.12 秒）找出每段；每段前後各多留一點再用 -45dB 修掉頭尾空白，開頭留約 20ms、結尾留約 50ms，加 8ms 淡入、30ms 淡出，不切到字。輸出 44.1kHz 單聲道 mp3（VBR q4）。
- 每段唸什麼是用語音辨識（whisper small，中文）逐段確認的，順序是萬 1～9、筒 1～9、條 1～9、東南西北、紅中、發財、白板；最後一列是切好的檔再辨識一次的結果。
- 原檔秒數＝在原始檔裡的起訖（silencedetect 的有聲區間）。
